# Luxury Auto Showroom & Dealership Management System

A bespoke, full-featured web application and management platform for luxury automotive dealerships.

## Key Features

- **Dynamic Showroom**: Live vehicle catalogue with real-time filters (powertrain, transmission, price range, availability) and full interactive photo gallery modal.
- **Admin Management Console (`/admin`)**:
  - **Vehicle Inventory & Cards**: Add, edit, remove vehicles, manage specs, and upload custom images directly in the UI.
  - **Client CRM**: Register buyers, track customer contact details, government ID/licenses, and purchase history.
  - **Payment & Transaction Tracker**: Record payments, track payment methods (Wire, Card, Cash, Crypto), and link with invoices.
  - **Invoice Builder & Printable PDF Generator**: Instant itemized invoice generation with tax/discount calculation, banking details, and print/save to PDF.
  - **Custom Dealership Branding**: Live logo upload, company profile customization, and theme toggle.
- **Data Layer**: Fully standalone local persistence engine with zero external dependencies.

## Development & Running Locally

```bash
bun install
bun run dev
```
